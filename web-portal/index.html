🎯 Automatic Target Calculation Rules & Limits

Configure section capacity boundaries, lower bound preferences, and target distribution algorithms.

Factory Target Calculation Modes

Mode A — Balanced Exact Distribution:
Distributes remaining allocatable balance evenly across available working days using integer division.
Mode B — Minimum-Target Driven:
Prefers configured minimum daily target, completing work in fewer days without exceeding balance or available WIP.
Mode C — Shipment-Deadline Priority:
Attempts to finish by shipment deadline up to maximum daily capacity. Flags plan infeasible if capacity is exceeded.
Mode D — Manual Planning Override:
Permits authorized planner to override target allocations subject to available WIP and audit logs.
